表示名設定ヘルプ

ダイヤ作者向けに、view_select.csvで変更できる表示名と、3つのページへの反映先をまとめています。

列車走行位置 ダイヤグラム 路線時刻表 ダイヤCSV入力 閲覧者向けヘルプ

設定ファイル

view_select.csvは、1列目に設定名、2列目に表示したい文字を入れるCSVです。

key,value
config_mode,simple

CSVが読み込めない場合は、各HTML内の初期表示名が使われます。

config_mode は basic または simple を指定します。日本語で 基本、簡易 と書くこともできます。

簡易モードでは、CSVファイル名が標準のままなら上記2行だけで動きます。CSVファイル名を変えたい場合だけ、該当行を追加してください。

祝日一覧の設定は不要です。土曜・日曜に加え、日本の祝日、振替休日、国民の休日は自動判定され、土休日CSVが使われます。

設定モード

config_mode,basic は基本モードです。view_select.csv 内の設定項目が通常通り反映されます。

config_mode,simple は簡易モードです。原則として各HTML内の初期値を使うため、CSVをほとんど編集せずに動かせます。

簡易モードでCSVから反映されるのは、config_mode と曜日別CSVファイル名だけです。駅リスト抽出の起点駅は、CSV内の最初の駅データ行から自動判定されます。

station_start_name駅リスト抽出の起点駅名です。列車走行位置、ダイヤグラム、路線時刻表で使われます。

branch_line_color支線カラーです。列車走行位置の支線表示に使われます。
extra_line_color_番号_prefix / extra_line_color_番号_color路線外路線カラーです。駅番号の先頭文字と色を組み合わせて設定します。例: TR と #369944
branch_anchor_code / branch_anchor_name支線が本線から分岐する駅番号・駅名です。
branch_station_番号_code など支線駅の駅番号、駅名、横位置、基準にする本線駅番号、縦位置を設定します。
branch_fallback_travel_sec支線駅間の時刻補間に使う既定所要秒数です。
type_color_種別名列車種別カラーです。例: type_color_特急,#164190
dest_initial_行先名駅時刻表に表示する行先略称です。例: dest_initial_新糸崎,新糸

列車走行位置 index.html

line_name と train_position_page_name が、画面上部のタイトルとブラウザタイトルに反映されます。

diagram_page_name と route_timetable_page_name は、上部のページ切替ボタンに反映されます。

route_links_visible、route_links_group_name、route_link_番号_label、route_link_番号_href は、設定モーダル内の他路線リンクに反映されます。

train_position_update_interval_seconds は、列車位置の再描画間隔に反映されます。

station_start_name は、駅リストを読み始める起点駅に反映されます。

line_color、branch_line_color、extra_line_color_番号_prefix、extra_line_color_番号_color、branch_anchor_*、branch_station_番号_* は、路線図の色と支線配置に反映されます。

type_color_種別名 と dest_initial_行先名 は、列車ごとの表示色と駅時刻表の行先略称に反映されます。

ダイヤグラム diagram.html

line_name と diagram_page_name が、ページ見出しとブラウザタイトルに反映されます。

line_short_name は説明文の「○○の列車ダイヤ」の部分に反映されます。

diagram_page_name は、上り/下り/上下のパネル見出しや読み込み中メッセージにも使われます。

train_position_page_name と route_timetable_page_name は、ページ切替ボタンに反映されます。

diagram_meta_visible は、ページ上部の運行日・CSV・列車数表示に反映されます。

csv_* は、表示する曜日別CSVに反映されます。祝日は自動判定され、土休日CSVが使われます。

station_start_name は、駅リストを読み始める起点駅に反映されます。

diagram_time_range_* は、時間帯選択の表示名と表示範囲に反映されます。

type_color_種別名 は、ダイヤ線・凡例・列車時刻表モーダルの種別色に反映されます。

路線時刻表 n_rosen.html

line_name と route_timetable_page_name が、ページ見出しとブラウザタイトルに反映されます。

route_timetable_page_name は、上り/下りの切替ボタン、各パネル見出し、表のアクセシビリティ用ラベルにも使われます。

train_position_page_name と diagram_page_name は、ページ切替ボタンに反映されます。

route_timetable_meta_visible は、ページ上部のダイヤ・駅数・列車数表示に反映されます。

csv_* は、表示する曜日別CSVに反映されます。祝日は自動判定され、土休日CSVが使われます。

station_start_name は、駅リストを読み始める起点駅に反映されます。

type_color_種別名 と dest_initial_行先名 は、列車時刻表の種別色と駅時刻表の行先略称に反映されます。
